# **Оценка стоимости квартиры методами машинного обучения**
*О проекте:* Основная цель данного проекта заключается в получении оценочной стоимости квартиры по ее ключевым параметра (жилая площаль, высота потолков, местоположение и т.д.).
Для реализации этой задачи была обучена модель градиентого спуска (lightGBM), которая была развернуть как API сервис через FastApi.
Также был создан простой сайт для ввода параметров квартиры, сервер которого также реализован через FastApi. Для возможности удаленного доступа к сайту был создан небольшой веб-сервер на nginx, в котором сайт и API-модели были запущены в Docker контейнерах.

*Данные:* В качестве первичных данных были использованы актуальные предложения о продаже недвижимости в Москве, размещенные в открытом доступе.

*Подготовка данных:* Была проведена предобработка данных: заполнение пропусков, удаление выбросов, кодирование признаков, преобразование адреса в координаты и т.д. 

*Модель:* В качестве обучающей модели была выбрана модель градиентного спуска, реализованная в библиотеке lightGBM. Для повышения точности был проведен подбор гиперпараметров.

*Результаты:* Для оценки качества модели была использована метрика R<sup>2</sup> - score. Результат на тестовой выборке равен 0.87.

*Запуск приложения:* API модели и сайта были реализованы через FastApi и запущены в Docker контейнерах. Работу приложения можно посмотреть по адресу http://136.234.69.100/.
